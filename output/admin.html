How to make the token (and what it can do)

GitHub → Settings → Developer settings → Fine-grained tokens → Generate new token.

  • Repository access — Only select repositories → pick just this one.
  • Permissions → Contents — Read and write. This is what commits the two config files.
  • Permissions → Actions — Read and write. Optional. Only needed for “Run pipeline now”. Leave it off and everything else still works.
  • Set the shortest expiry you can live with. Nothing here needs a long-lived token.

The token is stored in this browser’s localStorage so you don’t retype it. That means anyone with access to this browser profile can read it — use “Forget token” on a shared machine, and never paste a classic token with account-wide scopes.

Run pipeline now Needs Actions permission

Committing config does not re-collect the news. The push trigger deliberately skips the pipeline so design deploys stay free, which means a new source first appears at the next scheduled run (14:00 UTC). This button dispatches the workflow immediately instead.
