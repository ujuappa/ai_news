Tools & products Anthropic is turning Claude Code’s auto mode on by default

Anthropic is making 'auto mode' the default for Claude Code for Pro, Max, and Team accounts starting August 14. This feature allows Claude Code to proceed with actions unless they are irreversible or destructive, significantly reducing the need for human approval at each step. Testing showed auto mode to be safer, catching 89% of harmful actions compared to 13.6% for human review, and new safety features like prompt injection screening are being added.
