DeepSeek-V4.1-Flash: Pushing KV Cache Compression Limits
DeepSeek-V4.1-Flash is a multimodal Mixture-of-Experts (MoE) model with 552B backbone parameters, supporting contexts up to one million tokens, aiming to push KV cache compression limits. Its Causal Encoder-Decoder (CED) architecture activates 16B parameters per token during decode and 8B parameters during prefill, significantly improving efficiency for input-heavy workloads.

ProgramDistill: Benchmark for Interactive Web App Coding Agents
ProgramDistill is a new benchmark for evaluating coding agents on features inferred from interacting with fully functional reference applications rather than just issues or instructions. It uses a pipeline to discover 1,975 replay-verified behaviors across 26 applications, constructing 4,063 tasks, with GPT-6 Astra and Claude Opus 5 achieving 49.2% on it.
