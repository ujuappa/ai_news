UN turns to Google to make its global data AI-ready
The United Nations is collaborating with Google to launch the UN System Data Commons, built on Google's open-source Data Commons platform, to make its global statistics AI-ready and accessible via natural-language queries. This new system, which replaces the UNData portal, integrates the Model Context Protocol (MCP) to allow AI systems direct access to external data, aiming to improve the accuracy of AI-generated answers to development indicator questions, which currently average only 21.2%.
